# 🍄 قارچ‌پرداخت - Mushroom Payroll

نرم‌افزار موبایل مدیریت حقوق کارگران کارخانه قارچ

## ✨ امکانات

- ✅ ثبت کارها و کارخانه‌ها (یک بار و همیشگی)
- ✅ ثبت کارگران با امکان جستجو
- ✅ ثبت ماموریت‌های روزانه با تقسیم مساوی
- ✅ ثبت کسورات (قارچ، پیش‌پرداخت، جریمه)
- ✅ تسویه حساب مستقل برای هر کارخانه
- ✅ گزارش‌گیری ماهانه
- ✅ بکاپ و بازیابی اطلاعات

## 🛠️ تکنولوژی‌ها

- React Native + Expo
- TypeScript
- SQLite (دیتابیس آفلاین)
- NativeBase (کتابخانه طراحی)
- React Navigation (مسیریابی)

## 🚀 نصب و اجرا

```bash
# کلون کردن پروژه
git clone https://github.com/YourUsername/MushroomPayroll.git

# ورود به پوشه
cd MushroomPayroll

# نصب وابستگی‌ها
npm install

# اجرا
npx expo start --tunnel
